# Sipnetha — Online Tuition & Student LMS (Prototype)

A responsive, animated frontend prototype for **Sipnetha**, an online tuition and Learning Management System (LMS) designed for Sri Lankan secondary school students (Grades 6–11).

## Live Demo

Once hosted on GitHub Pages, the prototype can be accessed at:
`https://chamalka1998.github.io/sipnetha-lms-prototype/`

## Pages & Structure

- **`index.html`** — Public landing page with hero section, interactive grade highlights, and quick navigation.
- **`timetable.html`** — Grade 6–11 class schedule and subject explorer.
- **`teacher.html`** — Educator profile, qualifications, and teaching methodology.
- **`features.html`** — Overview of the Student LMS tools and platform benefits.
- **`login.html`** — Student ID and password portal login screen.
- **`dashboard.html`** — Authenticated student view with enrolled classes and live Zoom class access.
- **`vault.html`** — Past class video recordings archive and downloadable study resources.
- **`mcq.html`** — Interactive multiple-choice quiz interface for student self-assessment.

## Tech Stack (Prototype)

- **HTML5**
- **CSS3 / Tailwind CSS** (`css/`)
- **Vanilla JavaScript** (`js/`)
- **Static Assets & Imagery** (`assets/`)

## Local Setup

Clone the repository and open `index.html` directly in any modern web browser:

```bash
git clone [https://github.com/chamalka1998/sipnetha-lms-prototype.git](https://github.com/chamalka1998/sipnetha-lms-prototype.git)
cd sipnetha-lms-prototype
```
