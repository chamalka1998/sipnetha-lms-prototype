Chamodya Tuition Academy - Website + Student LMS (static prototype)

HOW TO OPEN
Double-click index.html. You need internet (Tailwind, fonts and icons load online).

WEBSITE PAGES: index.html (Home), subjects.html, timetable.html, teacher.html
LMS PAGES:     login.html, classes.html, lessons.html, homework.html, fees.html, account.html

HOW THEY CONNECT
Website "Student Portal" button -> login.html -> (Login button) -> classes.html
LMS side menu links the 5 LMS pages.
LMS logout icon -> index.html (website home)

FILES
css/fixes.css       layout fixes (one-line header, mobile menu, LMS drawer, spacing)
css/animations.css  calm animations (fade-in on scroll, soft hover)
js/site.js          mobile menu, LMS drawer, soft pop-up messages
js/animations.js    scroll fade-in, number count-up, progress bars, page fade
